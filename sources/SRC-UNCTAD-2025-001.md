## Notes

Per Codebook §18/§22 Rule 11, secondary index/database evidence establishes comparative patterns but should not substitute for primary evidence where authoritative primary sources are available.

**CTY-IND attribution note (2026-08-31):** the India Research Note lists this source (via `[[SRC-UNCTAD-2025-001]]`) but its Evidence/Data section places India's ranking figures (Overall 36th; R&D 3rd; Industry 10th; ICT 99th; Skills 113th; Finance 70th) under a header labelled "Source #3," which the note's own bibliography defines as a distinct PIB press release ("Transforming India with AI"), not this UNCTAD source. Given the figures match the UNCTAD Technology and Innovation Report's own Overall/R&D/ICT/Finance/Skills/Industry format exactly (as already used for CTY-BRA and CTY-CAN from this same source), they are attributed here to `SRC-UNCTAD-2025-001` rather than to the PIB source — a content-based attribution, not a fabrication, flagged transparently. See [EVD-IND-011](../02-Evidence/EVD-IND-011.md).

**CTY-JPN use (2026-08-31):** the Japan Research Note cites this source for Japan's UNCTAD ranking (7th overall; grouped among the "high-scoring" R&D countries). No attribution ambiguity in this instance. See [EVD-JPN-005](../02-Evidence/EVD-JPN-005.md).

**CTY-KOR use (2026-08-31):** the Korea Research Note cites this source for Korea's UNCTAD ranking (7th overall; 4th R&D; 5th Finance; 13th Industry; 14th ICT; 32nd Skills). No attribution ambiguity in this instance. See [EVD-KOR-007](../02-Evidence/EVD-KOR-007.md).

**CTY-SGP use (2026-09-01):** the Singapore Research Note cites this source for Singapore's UNCTAD ranking (5th overall; 4th Industry; 5th Skills; 12th ICT; 11th Finance; 20th R&D — notably Singapore's weakest sub-ranking is R&D, the opposite pattern from most other cases, consistent with its own strategy's emphasis on deployment/adoption over frontier R&D). No attribution ambiguity in this instance. See [EVD-SGP-010](../02-Evidence/EVD-SGP-010.md).
