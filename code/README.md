# Code

## Everything in this folder is newly written for this reproducibility package

The scripts that originally computed the network-density statistics and generated the
published SVG figures were run in a temporary working environment that was not part of
version control and no longer exists. They could not be recovered. **No original code is
included in this repository — there is none to include.**

What's here instead is a minimal, from-scratch reimplementation that:

- reads only the data already coded in `/data`, `/sources`, and `/evidence` (via the small
  CSV extracts in `data/`, each traceable back to its source table — see `data/PROVENANCE.md`);
- reproduces the network-density calculations using the same formula and the same
  `networkx` version (3.2.1) documented in `data/network/Stage5B-Network-Metrics-Dataset.md`;
- reproduces each figure's data content with a plain, functional plot — not a pixel-accurate
  copy of the published figure's custom design;
- introduces no new coding, no new category, no new statistic, and no recalculated or
  reinterpreted value. Every number a script prints should match a number already written
  in the corresponding `/data` file. If it doesn't, that is a bug in the script, not a new
  finding — please treat the `/data` record as authoritative and open an issue.

## Running it

```bash
pip install -r requirements.txt
cd code
python3 compute_network_density.py
python3 figure1_capability_matrix.py
python3 figure2_participation_coordination.py
python3 figure3_actor_configuration_network.py
python3 figure4_leverage_pathways.py
python3 figure5_pathway_breaks.py
```

Each figure script writes a PNG to `code/output/`. Python 3.9+ is sufficient; no other
system dependencies (no LaTeX, no Cairo, no Node) are required.

## What this code is not

It does not recreate the research process, re-derive any coding decision, or introduce any
methodological choice beyond what `/codebook` and `/data` already document. It exists solely
so a reader can check the published data-derived results and regenerate an equivalent version
of each figure from the materials in this repository, per the Codebook's own network-analysis
safeguard (`/data/network` README: no new construct, scale, or metric without prior approval —
none is introduced here).
